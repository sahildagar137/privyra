// My Work

Projects

PROJECT 01

Network Security / VLAN

Inter-VLAN Routing with 802.1Q Trunk

Designed and configured a multi-VLAN network environment with Inter-VLAN routing using IEEE 802.1Q encapsulation (DOT1Q). The topology connects two remote sites via serial links with trunk ports enabling seamless communication between VLANs across different network segments.

  • Configured VLAN 1 & VLAN 2 with proper segmentation
  • Implemented 802.1Q trunk encapsulation on router sub-interfaces
  • Established WAN connectivity using serial interfaces
  • Verified end-to-end connectivity with ICMP ping tests
Cisco Packet Tracer VLANs 802.1Q Trunking
PROJECT 02

Network Engineering / Topology

Enterprise Mesh Network Topology

Built a complex enterprise-level mesh network topology with multiple routers and switches interconnected for redundancy and fault tolerance. The design ensures high availability with multiple routing paths, simulating a real-world corporate network infrastructure.

  • Designed mesh topology with 7+ routers for redundancy
  • Configured multiple routing paths for fault tolerance
  • Connected 6+ switches with end-user PCs
  • Tested network resilience with ICMP and PDU simulations
Cisco Packet Tracer Mesh Topology Routing Redundancy
PROJECT 03

Routing Protocol / OSPF

OSPF Multi-Area Routing Configuration

Implemented OSPF (Open Shortest Path First) routing protocol across multiple areas to simulate a departmental network. Area 1 serves the IT department while Area 2 handles the Sales department, with 4 routers connected via serial links ensuring proper inter-area communication.

  • Configured OSPF multi-area routing (Area 1: IT, Area 2: Sales)
  • Set up 4 routers with serial WAN connections
  • Implemented proper subnet addressing across all segments
  • Verified routing tables and inter-area connectivity
Cisco Packet Tracer OSPF Multi-Area WAN Links
