Inter-VLAN Routing with 802.1Q Trunk

Designed a multi-VLAN network with Inter-VLAN routing using IEEE 802.1Q (DOT1Q) encapsulation. Two remote sites are connected via serial WAN links with trunk ports enabling seamless cross-VLAN communication.

  • Configured VLAN 1 & VLAN 2 with proper network segmentation
  • Implemented 802.1Q trunk encapsulation on router sub-interfaces
  • Established WAN connectivity using serial interfaces (Se2/0)
  • Verified end-to-end connectivity with ICMP tests — all packets successful

Linux / Security

SSH Remote Access Hardening & Security

Configured and hardened SSH (Secure Shell) on a Linux server for secure remote administration. Implemented key-based authentication, disabled root login, changed default ports, and deployed Fail2Ban for brute-force protection — making the server resilient against unauthorized access.

  • Generated Ed25519 SSH key pairs for key-based authentication
  • Disabled root login & password authentication in sshd_config
  • Changed SSH port from 22 to custom port (2222) to reduce attacks
  • Deployed Fail2Ban — auto-bans IPs after 3 failed login attempts
  • Configured AllowUsers directive for user-level access control
